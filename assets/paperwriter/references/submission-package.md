# Compare and prepare a multi-file submission package

Read this when the author supplies a complete submission folder, asks how it differs from an earlier generated draft, or asks the skill to learn from the final revisions. Use the current files as the comparison target; do not treat a folder named “final” as scientific approval.

For an editorial-office technical return concerning word counts, article type or figure/table uploads, also read [technical-resubmission.md](technical-resubmission.md). Begin from the files actually submitted, including author changes to figure allocation, combined NMR tables, title, author details and declarations; do not replace them with an older generated package.

## Compare versions by role

1. Inventory the latest package and map each file to its earlier counterpart: manuscript, SI, figures, graphical abstract, cover letter, Highlights, and any journal-specific forms. Confirm which version was generated by the skill and which was revised by the author or others. Compare editable content as well as filenames, formats, slide/page counts and figure hashes when relevant. Identical figures need no invented change narrative.
2. First describe the change in the paper's argument: what question the Introduction now motivates, what the Results foreground, what structural or mechanistic distinction receives emphasis, and whether the Abstract and Conclusion state the same supported contribution. Separate better selection and ordering from new results or corrected data supplied after the first draft.
3. Check the submission materials as one message: the cover letter explains contribution and journal fit; Highlights select a few searchable findings; the graphical abstract visually conveys the source, method and principal outcome. They should agree with the current manuscript without copying its full Abstract or adding unsupported activation, mechanism, therapeutic or novelty claims.
4. Check what moved between main text and SI. A shorter manuscript is useful only if essential method conditions, endpoint definitions, controls, replicate types and data needed to interpret results remain in the manuscript or in a clearly cited SI location. In particular, compare the earlier and later Methods sentence by sentence for dropped numbers, ranges, incubation times and decision thresholds. A familiar endpoint name such as MIC does not replace its explicit operational rule.
5. Check package integrity at handoff: document and figure versions, numbering, captions, names, units, target-journal requirements, rendered legibility, one-page/one-slide exports where intended, image dimensions and resolution. Verify submission copies, not just editable masters. Keep figures editable where practical and preserve author-owned chemical structures and research images rather than redrawing them with a generative image model.

## Learn only the transferable decision

Classify each change as an editorial improvement, evidence correction/addition, journal-format adaptation, cosmetic preference, or a possible overstatement/error. For an editorial improvement to the skill's own draft, ask what first-draft choice should have led to the better result: more selective background, a clearer evidence sequence, a shorter cover letter, or a more explicit result hierarchy. Preserve that decision rule, not the project-specific species, assay values, structures or preferred colors.

Do not teach the skill to imitate an author's unsupported stronger language. A causal claim about a culture condition, gene cluster or structure–activity relationship requires evidence beyond co-occurrence or a small analogue comparison. Label such a change as a verification item even when it appears in a file the author calls final. Likewise, do not infer that deleting a negative result, control, endpoint threshold or assay detail was an improvement merely because the revised paragraph is smoother.

For the user-facing comparison, give the few consequential changes with concrete locations and explain the resulting logic. Separate confirmed changes from scientifically unverified additions. If a discovered discrepancy could affect submission, name the exact file, section or searchable phrase and a concrete correction or record to check. Do not silently edit the author's submission package during a request to compare and learn.
