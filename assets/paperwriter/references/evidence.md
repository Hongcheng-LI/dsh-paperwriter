# Evidence

For a scaffolded full project, inventory inputs with project_tools.py inventory --root "<project-root>" --scope research. This reads bytes for hashes, not scientific content. In a legacy layout or focused task, record the actual in-scope source paths and versions without forcing them into the script's fixed input directories. Inspect metadata and samples before deeper analysis. Large data can remain in its existing author-controlled location via a documented manifest; do not copy it merely to satisfy a folder convention. Do not follow linked external locations without scope confirmation.

Define which data belong to this manuscript, including overlap with other manuscripts. Keep exclusions and their reasons. Do not silently exclude negative, null or contradictory results.

Build result units and methods links. Common fields: object/sample, conditions, controls/comparators when applicable, raw observation, processing, uncertainty, source location, version, corresponding methods and output. Adapt fields to qualitative studies, theory, simulations, engineering and mixed designs. Never infer that absence of a biological-replicate field makes a nonbiological study incomplete.

Separate source_level (raw record, derived analysis, author summary, draft, external literature) from verification_scope (file readable, extracted, summary cross-checked, original checked, independently reproduced). Claim states: supported, provisional, conflicted, missing, out_of_scope. No state automatically licenses causal or absolute wording.

Source conflicts: record each value/interpretation and locator, adopted handling, supporting rationale, author confirmation if applicable and downstream effects. A recent author's correction is explicit evidence of a correction; if it conflicts with raw records, keep that discrepancy visible.

Classify issues as blocking, draftable, optional. Blocking means blocks the affected core claim or submission, not necessarily every useful task. Draftable gaps use stable markers [PENDING:ISSUE-0001]. Provisional claims can appear with justified qualifications; do not invent results to remove markers.

Routine checks: relevant missingness, duplicates, identifiers, units, batches, methods/results concordance, technical vs independent replicates, data-to-figure consistency and documented analysis parameters. Additional analyses that alter study interpretation need an agreed plan. Preserve raw data and record code, inputs, software, parameters and random seeds where applicable.

Scope specialist limits: extracted spectra are not independent structure elucidation; re-running code is not proof of research validity; unknown literature novelty is not established novelty. Request targeted evidence, not a long undifferentiated questionnaire.

Templates in assets/templates contain starting fields. Create them only at this phase, extend with domain fields in a documented way, and keep stable IDs.
