# Manuscript and Supporting Information consistency

Use for SI preparation, revised-package review, image-to-table transcription, and the conditional scientific checks below. Keep project-specific values and decisions in the project, not in this skill.

## Establish the current evidence before writing

- Identify the latest saved manuscript and SI, and whether the task is review, revision, or table preparation. Read those artifacts rather than regenerating from older section drafts.
- For an author correction, record the field, prior value, corrected value, date/source, verification scope, unresolved raw-record conflict, and affected outputs. Author confirmation establishes what the author reports; it does not itself independently validate the scientific conclusion.
- Trace corrections through Abstract, Results, Methods, structures, captions, tables, SI contents and evidence cards. Provenance, processing-stage masses, identifier mappings and configuration labels often recur in several places. Reopen only the affected decisions.
- Keep selection rationale in its actual chronology. Subsequent activity testing does not establish why a culture or sample was originally selected. A quantity before processing is not interchangeable with its quantity after processing.

## Transcribe and construct tables

1. Read the complete source table visually, including continuations, headers, units and notes. Use extraction to assist, and return to the image when encoding, merged cells or column placement is ambiguous.
2. Verify every ingredient/analyte name, number, unit, hydrate, sign and row/column association against the source. Translate the actual term; do not substitute a familiar reagent or standard recipe. For example, 色氨酸 is tryptophan, not glycine. Preserve unusual values as source values pending resolution rather than silently normalizing them.
3. Keep preparation bases explicit: per liter, per flask, added water volume, solid substrate mass, stock concentration and final assay concentration describe different quantities. Do not convert a solid culture into a liquid volume without a documented basis. Carry a contradiction as a short pending field and a source-linked author query.
4. Preserve the distinction among zero, below detection, inactive in the tested range, not tested and not reported. A blank cell alone does not establish that an assay or control was not performed. Retain source blanks with a neutral note such as “blank cells: no value reported in the source table” unless their meaning is documented. Define a dash only when its meaning is supported; otherwise flag it for confirmation.
5. Preserve relevant negative results. If a source figure shows a larger tested panel than the accompanying numeric table, identify that coverage difference. Do not invent exact values from a schematic chart or describe the smaller table as the complete experiment. Seek existing numeric records or clearly disclose the supported subset.
6. Keep assay types separate: inhibition-zone diameter, MIC and cell-growth inhibition require different headings, units, controls and notes. Apply inoculum, solvent, incubation and endpoint corrections only to the assay they concern. Never transfer conditions from purified-compound testing to crude-extract screening without evidence.
7. Single reported values are not automatically means. Replicate counts do not justify invented SDs, independent biological replicates or statistical tests. Preserve documented control results and state doses separately when controls and samples were tested at different concentrations.

## Integrate the artifact without losing content

- Inspect both the contents list and the actual body. A caption can label the wrong table; do not assume the table under it is disposable. Preserve and relocate a valid misplaced table to its supported destination when authorized, or retain it in a clearly identified working record.
- Use the requested editing mode; create a derived review copy when the source must remain intact. Keep author queries separate from clean submission content, or conspicuously mark a working copy that contains them.
- Check chemical-name translation and numeric transcription separately from English polishing. Then render the output to check species italics, formulas, table widths, split rows, notes, panel labels and cross-references. XML validation and a visually intact page do not validate scientific content.
- Report what changed, which source supported it, and what remains unresolved. A prepared table may be complete as a working draft while the SI package remains incomplete.

## Conditional check: stereochemical and computational evidence

Apply only when the manuscript makes configuration assignments.

- Separate planar structure, relative configuration and absolute configuration, and identify the evidence supporting each. Similar local NMR shifts and the same sign of specific rotation do not alone establish identical absolute configuration across different compounds. Label an analogy-based assignment according to its actual support.
- For experimental/calculated ECD comparisons, check enantiomer labels, signs, peak positions, band shapes and the reliable spectral range. A screenshot can support a qualitative comparison; it does not establish numerical similarity, raw-data quality or a reproducible calculation. Same-sign bands alone do not establish a strong overall match. Do not upgrade “tentatively assigned” solely because the author prefers a definite assignment.
- Report actual conformer search, optimization, energy/weighting and excited-state calculation stages. Verify software/version, level, solvent model, conformer weights, line shape, broadening definition, shifts and scaling where relevant. Do not equate sigma, half-width and FWHM or infer actual settings from software defaults or a tutorial.
- Check whether axes show raw ellipticity, molar circular dichroism, arbitrary units or normalized values. Converting experimental ellipticity requires the recorded concentration and path length; a changed label alone does not make values comparable.
- Retain contradictory or unreproducible ORD/rotation results in the evidence record. Distinguish retaining historical information from using it as confirmatory evidence. If ECD is adopted as the assignment basis, reconcile configuration labels across text, drawings, captions and SI; disclose unresolved conflicting evidence rather than claim independent agreement.

## Practical checks when updating this workflow

Review the proposed instructions against representative cases: an author changes sample provenance; a source recipe has an impossible volume; a control cell is blank; a caption covers a misplaced valid table; an ECD label changes without new evidence; a Word revision fixes an issue from an earlier review. The desired outcomes are traceable corrections, preserved data and proportionate claims. A static skill validator checks packaging, not these scientific judgments; do not report an independent behavioral test unless one was actually run.
