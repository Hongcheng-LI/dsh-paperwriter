# 从这里开始

本目录由 paperwriter 初始化。此时不要求材料已经齐全，也不会自动分析空目录或生成手稿。你可以现在一次性放入全部材料，也可以分阶段补充。

先告诉助手明确的目标期刊。助手会从期刊或出版社官网获取最新的 Aims and Scope 与 Guide for Authors，保存到 01_inputs/01_target_journal/author_guidelines，并记录网址和访问日期；如果官网提供 Word 模板，也会保存到 journal_templates。你只需把相近论文放入 01_inputs/01_target_journal/reference_articles。文章类型和一段研究简介可以直接告诉助手，也可以稍后写入 00_project/project.json。期刊材料准备好后告诉助手“期刊材料已放好”。

第一阶段会读懂参考论文，解释它们怎样组织论证，并提出适合你研究的候选架构，供你确认。需要长期检索或明确要求建库时，再构建细化的文章/段落/句子语料。完整研究材料可以提前放好，但将在期刊阶段确认后处理。

研究材料可随时放入 01_inputs/02_research_materials：原始数据与结果、详细方法、分析代码、图表、已有稿件、项目文献和补充记录分别进入名称对应的子目录。材料都可以提前放好，但完整流程会先分析目标期刊，再建立本项目证据。大型或专有格式数据可提供位置清单和可读导出，不必重复复制。涉及隐私的材料先按研究要求处理。

导师或喜欢的研究者论文可选，放入 01_inputs/03_preference_papers。缺少它们不影响工作。

所有输入默认只读。语料在 02_corpus，项目证据在 03_evidence，写作蓝图在 04_manuscript_plan，工作稿在 05_drafts，核验报告在 07_quality_control，作者确认后的投稿包在 06_submission。初始化重复运行不覆盖已有文件。

请在 00_project/project.json 填写基本信息，也可以直接在对话中提供，由助手记录。阶段和确认保存在 status.json；不要仅因文件齐全就手动认定科学核验完成。新项目默认以 05_drafts/merged_manuscript/manuscript.docx 作为唯一工作主手稿，便于导师和合作者直接修改；别人返回修改后的 Word 文件后，应先将它确认为最新版本再继续写作。

不需要先自己想好整篇故事线。告诉助手你最重要的结果或提供已有图表，助手会结合当前阶段提出主线、段落安排和下一步写作建议。已有项目可沿用原目录；只修改一节时不必重新走完整流程。

本工具提供写作和核验流程，不代替作者的科学判断。自动检查不会证明无抄袭、数据绝对正确或论文必被接收。
